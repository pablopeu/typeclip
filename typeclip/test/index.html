Payloads → portapapeles
1) input dentro de un <form> (Enter NO debe enviarlo)
2) textarea
3) contenteditable
4) composer fake tipo X (Draft.js-like + typeahead de menciones)
👤 pablo — Enter para elegir

Si el texto tipeado contiene @pablo seguido de Enter, este editor se "come" el Enter para elegir la sugerencia (imita el comportamiento del composer real). La verificación final de la extensión tiene que marcar DIF en ese caso.

5) editor async (Lexical/ProseMirror-like: inserta 60 ms después)

Este editor intercepta beforeinput, lo cancela y aplica el texto 60 ms después (render diferido, como los editores basados en modelo). La sonda de caracteres especiales de la extensión tiene que esperar ese delay en vez de duplicar el caracter.
